## 🚀 About This Repository

I'm a self-taught programmer with no formal CS degree.  
This repository is my public learning log, portfolio, and workspace.

It contains:

- 📘 Study notes written in my own words
- 🧪 Hands-on code and experiments
- 🧩 Data structures & algorithm implementations in C
- 🌐 Socket programming and network projects
- ✅ LeetCode solutions with explanations
- 🗺️ A clear roadmap showing what I'm learning and why

The goal is not just to *use* computers, but to understand how they really work.
